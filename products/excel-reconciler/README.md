# Excel / CSV Reconciler

Мини-продукт для коммерческих заказов по сверке Excel/CSV.

## Что делает

- принимает два CSV/XLSX-файла;
- сравнивает строки по выбранному ключевому столбцу;
- находит строки, которые есть только в первом или только во втором файле;
- находит совпавшие ключи с различающимися значениями;
- находит дубли ключей в каждом источнике;
- формирует Excel-отчёт с отдельными листами `summary`, `only_first`, `only_second`, `changed`, `duplicates_first`, `duplicates_second`;
- подходит для сверки выгрузок из CRM, банковских операций, реестров, складских таблиц, каталогов и редакционных списков.

## Демо

В `demo/source_a.csv` и `demo/source_b.csv` лежат полностью синтетические данные.

В них специально заложены ситуации:

- заказ `1004` есть только в первом источнике;
- заказ `1006` есть только во втором;
- по заказу `1002` изменились сумма и статус;
- по заказу `1005` изменился менеджер;
- `1004` продублирован в первом источнике.

Запуск демо:

```bash
python products/excel-reconciler/reconcile.py \
  products/excel-reconciler/demo/source_a.csv \
  products/excel-reconciler/demo/source_b.csv \
  --key order_id \
  --output products/excel-reconciler/demo/reconciliation_report.xlsx
```

## Коммерческий формат

Базовая услуга: «Сверю два Excel/CSV и сделаю отчёт по расхождениям».

Стартовая цена для первых заказов: 3 000–5 000 ₽ за простую сверку. Более сложные правила, несколько файлов, нормализация данных и регулярный запуск оцениваются отдельно.

Клиенту можно отдать либо готовый отчёт без передачи кода, либо скрипт + инструкцию + отчёт.

## Что можно адаптировать под клиента

- несколько ключевых полей вместо одного;
- нечёткое сопоставление названий;
- нормализация телефонов, e-mail, артикулов и дат;
- игнорирование выбранных колонок;
- допуски для числовых значений;
- сравнение десятков файлов за один запуск;
- автоматический запуск по расписанию;
- Google Sheets / облачные папки / API;
- отдельный отчёт для бухгалтерии, продаж, склада или контента;
- простой веб-интерфейс.

Все данные в репозитории демонстрационные. Реальные клиентские выгрузки в публичный репозиторий не добавляются.
